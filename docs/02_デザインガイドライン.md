# デザインガイドライン v1.0 — Mimamori（みまもり）

> 参考アプリ: **iSharing**（主）, **OneLocator**, **Life360**, **Zenly**
> 収集した参考画像11枚を分析して策定。

## 0. 最重要の分析結果

> ⚠️ 参考画像のカラフルなグラデーション背景は **App Store の宣伝画像**であり、
> **アプリのUIではない**。実際のアプリ画面（スマホの中身）はすべて
> **白基調・クリーン・アクセント1色**である。
>
> → Mimamori も **白基調 + アクセント1色**で作る。装飾は最小限。

### 参考アプリの内訳
| アプリ | 枚数 | 特徴 |
|---|---|---|
| **iSharing** | 6枚 | 白基調・青アクセント・地図中心。**これを主軸にする** |
| OneLocator | 2枚 | 白基調・青・セーフゾーンとバッテリーの表現が優秀 |
| 紫系ロケーター | 1枚 | 紫アクセント・ピンのデザインが参考になる |
| Zenly系 | 2枚 | ネオン・カワイイ。**採用しない**（信頼感が下がるため） |

### 共通デザインDNA（全アプリに共通）
1. 地図が全画面、UIはその上に浮く
2. **しずく型アバターピン**（丸い写真＋下向きの尖り）
3. ピンに**バッジが付く**（下＝バッテリー、上＝速度・名前）
4. **ボトムシート**（ドラッグハンドル付き）にメンバー一覧
5. 地図の端に**白い丸型フローティングボタン**
6. 角丸 16〜20px、やわらかい影、アクセント1色

## 1.5 🌗 時間連動テーマ（昼／夜の自動切替）

> **本アプリの重要な特徴。** 実時刻に応じてライト／ダークを自動で切り替える。

| 時間帯 | テーマ |
|---|---|
| **5:00 – 18:00** | ☀️ ライト（昼） |
| **18:00 – 5:00** | 🌙 ダーク（夜） |

### なぜ必要か（機能的な理由）
1. **夜間の使用が中心のアプリ** — 帰り道の見守りは夜に使う
2. **暗所で画面が眩しいと危険** — 目が暗さに慣れず、周囲が見えなくなる
3. **画面の光で自分の居場所が目立つ** — 夜道での安全上の配慮
4. **OLEDでは電池を節約できる** — バッテリー残量が機能の一部である本アプリでは特に重要

> 装飾ではなく**安全性と省電力のための設計**である。

### 設定
`設定 > テーマ` で **自動 / 常にライト / 常にダーク** を選べる。既定は**自動**。

### ダークパレット
```css
html.night{
  --brand:#4D9FFF;        /* 暗い背景でも視認できるよう明度を上げる */
  --brand-soft:rgba(77,159,255,.14);
  --online:#34D97A; --warn:#FBB040; --danger:#FF5A5A; --offline:#6B7078;

  --surface:#141519;      /* シート・カード */
  --surface-2:#1E2025;
  --border:rgba(255,255,255,.09);
  --text:#F2F4F6; --text-sub:#9BA1A9; --text-mute:#6B7078;

  /* 浮くボタンは「白」ではなく「半透明の暗色 + ぼかし」 */
  --fab-bg:rgba(30,32,37,.88); --fab-ic:#F2F4F6;
  /* CTAは反転（白背景・黒文字）*/
  --cta-bg:#FFFFFF; --cta-tx:#141519;
  --pin-ring:#141519;     /* ピンの縁は白ではなく背景色にする */

  --map-bg:#16181C; --map-road:#2B2F36; --map-water:#152532;
  --map-park:#1A2620; --map-bld:#1E2126; --map-label:#5A6069;
}
```

### ダーク化するときの原則（参考画像のミニマルUIより）
| 要素 | ライト | ダーク |
|---|---|---|
| フローティングボタン | 白・影 | **半透明の暗色 + `backdrop-filter: blur`** + 細い枠線 |
| ピンの白縁 | `#FFF` | **背景色**（`--pin-ring`）。白だと浮きすぎる |
| 主要ボタン | 黒背景・白文字 | **反転して白背景・黒文字** |
| 区切り線 | 黒 8% | **白 9%** |
| 影 | 弱い | **強くする**（暗色同士は影が見えにくいため） |
| アクセント色 | `#2F6BFF` | **明度を上げて** `#4D9FFF` |

> ⚠️ ダークは「色を反転する」のではなく、**各要素を作り直す**。
> 特に「白い縁」「白いボタン」をそのまま流用すると、浮いて安っぽく見える。

### 地図タイル
| テーマ | タイル |
|---|---|
| ライト | **CartoDB Positron** |
| ダーク | **CartoDB Dark Matter** |

切替時は 0.5秒のフェードで違和感をなくす。

### 実装（実装済み 2026-07-31）
```jsx
// src/hooks/useTimeTheme.js
const NIGHT_START = 18, NIGHT_END = 5;
const isNightAt = (d = new Date()) => {
  const h = d.getHours();
  return h >= NIGHT_START || h < NIGHT_END;
};
// mode: 'auto' | 'light' | 'dark' （zustand + localStorage に保存）
// auto のときは 1分ごとに現在時刻を見て class を更新
```
`<html>` に **class を2つ**付け外しするだけで全体に反映される
（すべての色がCSS変数のため）。

| class | 対象 |
|---|---|
| `night` | 自作トークン（`index.css` の `html.night`） |
| `dark` | shadcn/ui のトークンと Tailwind の `dark:` バリアント |

> ⚠️ **2つとも**必要。片方だけだと shadcn 製のコンポーネントが
> 暗い背景の上で白いまま残る。

## 4. コアコンポーネント仕様

### 4.1 🎯 アバターピン（最重要 / 全参考アプリ共通）

```
        ┌──────────┐
        │  MIKE    │ ← 名前バッジ（任意・上）
        └────┬─────┘
         ╭───────╮
         │ 写真  │  ← 円形 56px、白枠 3px
         ╰───┬───╯
             ▼        ← しずくの尖り（8px）
        ┌─────────┐
        │ 🔋 12%  │   ← バッテリーバッジ（下）
        └─────────┘
```

| 要素 | 仕様 |
|---|---|
| アバター | 円形 **56px**（自分は 48px）、白枠 **3px**、`--shadow-pin` |
| 枠の色 | ステータス色（共有中=緑 / オフ=灰 / SOS=赤・点滅） |
| しずくの尖り | 下向き 8px。**位置の正確な一点**を指す |
| 上バッジ | 名前 or 速度（`🚗 30km/h`）。11px、白背景、角丸full |
| 下バッジ | バッテリー（`🔋 12%`）。残量で色が変わる |
| タップ | メンバー詳細シートを開く |

**自分のピン:** 青い丸（`--brand`）＋精度円（薄い青、半透明）。アバターは出さない。

### 4.2 📋 ボトムシート

```
━━━━━━━━━  ← ドラッグハンドル 36×4px, --text-mute
```

| 項目 | 仕様 |
|---|---|
| 停止位置 | 3段階: **小**(120px) / **中**(50%) / **大**(90%) |
| 角丸 | 上のみ `--r-sheet` |
| 影 | `--shadow-sheet` |
| ハンドル | 36×4px、角丸full、上部中央に 8px の余白 |

### 4.3 ⚪ フローティングボタン

| 項目 | 仕様 |
|---|---|
| サイズ | **44px** 円形（タップ領域の最低基準） |
| 背景 | 白、`--shadow-float` |
| アイコン | 22px、`--text` |
| 配置 | 地図の左右端、縦に並べる（間隔 10px） |

**SOSボタンだけ例外:** 文字「SOS」を `--danger` 色で表示。

### 4.4 👤 メンバーリスト項目

```
┌────────────────────────────────────┐
│ ⬤ [写真] こうた 山田            ›  │
│   🔋     Irvine · 今                │
└────────────────────────────────────┘
```
- 左上に**オンラインドット**（8px、緑）
- アバター右下に**小さなバッテリーバー**
- 2行目: `場所 · 最終更新` （例:「Irvine · 今」「Irvine · 5分前」）

> 📌 **最終更新時刻は必ず表示する。** Webはバックグラウンド追跡ができないため、
> 「今」なのか「1時間前」なのかを隠さないことが誠実な設計。

### SC-P01 セーフゾーン — OneLocator 準拠

- 地図に**カテゴリ色の円**（自宅=緑 / 学校=紫 / 職場=青）＋アイコン＋名前
- 一覧: アイコン・名前・`有効`バッジ・`半径 200m`
- **ゾーン履歴**: タイムライン形式で `入室`（緑）/ `退出`（赤）＋時刻

### SC-S01 SOS

- 中央に**大きな赤い円ボタン**（直径 200px）＋**進捗リング**
- 状態は3つ:

| 状態 | 円の中身 | 下部 |
|---|---|---|
| 待機 | `SOS` ＋「タップで送信」 | — |
| カウント中 | **残り秒数を大きく**（72px）＋リングが減る | `キャンセル`（**1タップ**・大きく） |
| 発信済み | `送信中` ＋脈動アニメ | `キャンセル（長押し）` |

- カウント中は**1秒ごとに `navigator.vibrate()`**。無反応だと壊れたと思われる
- 発信後:「**緊急通報を送信しました**」＋通知先アバターに ✓
- 下に現在の住所

> ⚠️ **長押しにしない。** 理由は企画書 §2.6。
> 端末を持ち続けられない状況こそ SOS が要る場面なので、
> 「押し続けたら送る」ではなく「止めなければ送る」にする。

### SC-M04 呼び出し受信（F-11）

- 全画面。橙（`--status-warning`）の背景、大きなアバター、`〇〇さんが呼んでいます`
- **主ボタンは1つだけ**（`大丈夫だよ`）。白地・大きく・下部に配置
- その下に目立たないテキストリンク `あとで返す`（音だけ止める）
  → 逃げ道がないと端末ごと閉じられ、親に何も届かなくなる。理由は企画書 §2.3
- 音が鳴っている間は状態バッジ `音が鳴っています` を出す。**タップで消音**できる
- 最下部に「タップすると、〇〇に『大丈夫』と位置情報が届きます」= 何が送られるか明示する

> ⚠️ この画面だけは**夜テーマでも橙のまま**にする。
> 緊急の合図なので、周囲のUIと同じ色調に溶け込ませない。

## 7. 地図 — 改定（2026年8月31日）

> **⚠️ 2026年7月30日の決定（CARTO Positron / Dark Matter）は破棄した。**
> CARTO がキー無しのタイルに「API KEY REQUIRED」の透かしを入れる方針に変わり、
> 地図が読めなくなったため。前提だった「APIキー不要」が成り立たなくなった。
> デプロイして初めて気づいた——**外部サービスの無料条件は、こちらの都合で
> 変わらない保証がない**。選定理由に「無料だから」を置くなら、変わったときに
> 何に乗り換えるかまで決めておくべきだった。

### 採用
| 項目 | 選定 | APIキー | 費用 |
|---|---|---|---|
| ライブラリ | **Leaflet** + `react-leaflet` | — | 無料 |
| タイル | **国土地理院 淡色地図** | 不要 | 無料 |
| 逆ジオコーディング | **国土地理院（GSI）** | 不要 | 無料 |

```
https://maps.gsi.go.jp/xyz/pale/{z}/{x}/{y}.png
```

※ 帰属表示（attribution）に「国土地理院」を必ず入れる。
※ **最大ズームは18**。19以上は404になり、拡大した先が白紙になる。
※ 旧ホスト `cyberjapandata.to.gsi.go.jp` は名前解決できない（NXDOMAIN）。配信元は `maps.gsi.go.jp`。

### 夜テーマ
国土地理院に暗色版は無いので、**同じタイルを CSS フィルタで反転**する
（`index.css` の `.mm-tiles-dark`）。

```css
filter: invert(1) hue-rotate(180deg) brightness(0.92) contrast(0.9);
```

⚠️ `invert` だけだと色相まで反転し、川が橙、緑地が紫になる。`hue-rotate(180deg)` で
色相だけ戻すと、明暗だけが反転した自然な暗色地図になる。
⚠️ かける先は**タイルの層だけ**。地図全体にかけるとピンやラベルまで反転して読めなくなる。

### 選定理由
1. **APIキーもクレジットカードも不要** — ポートフォリオでは最重要。デモを誰かに大量アクセスされても課金されない
2. **住所の逆ジオコーディングと提供元がそろう**。地図と住所が別々の出典だと、表示がずれたときに切り分けが増える
3. 日本の国土を管轄する機関の地図なので、**日本向けアプリとして素性がはっきりしている**
4. 参考アプリ（iSharing / OneLocator）と同じ**淡色の地図**

### 割り切り
**日本国外はタイルが無い**（404 → 白紙）。日本国内向けのアプリなので許容する。
世界中で使うなら、キー付きの CARTO か MapLibre へ移ることになる。
4. アバターピンは Leaflet の `divIcon` で HTML/CSS をそのまま流用できる
5. ジオフェンスは `L.circle`、移動履歴は `L.polyline` が標準で使える

### 採用しなかったもの
| 候補 | 却下理由 |
|---|---|
| **Google Maps** | 無料枠内でも**クレジットカード登録が必須**。2025年に課金体系が変更され従量課金のリスクあり。テーマ切替も Cloud 側の Map ID 設定が必要。※日本のPOIデータは最良なので、将来商用化するなら再検討の価値あり |
| Mapbox | MapLibre で代替できるため、キー＋カード登録の手間に見合わない |
| MapLibre GL | 細かい再配色ができるが、淡色路線に決めた今は Leaflet で十分。**将来の乗り換え先候補** |
| OSM 標準タイル | 色が濃すぎてピンが埋もれる |
| 国土地理院タイル | 正確だが見た目が古く、アプリの雰囲気に合わない（※逆ジオコーディングのみ採用） |

### 逆ジオコーディングの運用ルール（重要）
地図タイルとは**別のAPI**。「みなと通り 3丁目 付近」「自宅」の表示に必要。

- **国土地理院の逆ジオコーディング API** を使う（キー不要・日本の住所に強い）
- **必ず住所をDBにキャッシュする。** 位置は30秒ごとに届くが住所はほぼ変わらないため、
  **前回から約100m以上移動したときだけ**問い合わせる
- 取得できなかった場合は住所欄を空にし、時刻表示だけにする（嘘の住所を出さない）

> 代替: OSM の Nominatim も無料だが **1リクエスト/秒**の制限があり、大量利用は規約違反。
> デモ程度なら可。

## 8. モーション

| 対象 | 動き |
|---|---|
| ピンの移動 | 位置更新時に **0.5秒でスムーズに移動**（瞬間移動させない） |
| ピンの出現 | 0.3秒でポップイン（scale 0.8→1） |
| シート | ドラッグ追従＋離したらスナップ（spring） |
| SOSリング | 長押し中に3秒かけて一周 |
| オンラインドット | ゆっくり脈打つ（2秒周期） |
| 呼び出し受信 | 背景が赤くフラッシュ（1秒周期） |

> 装飾的なアニメーションは**入れない**。すべて「状態を伝える」ためだけに使う。

## 9. 実装方針

すべての色・角丸・影は **`src/index.css` の CSS変数**に集約する。
デザイン変更時はこのファイルだけを編集すれば全体に反映される。

```css
:root {
  --brand: #2F6BFF;
  --online: #22C55E;
  /* ... 上記すべて ... */
}
```

Tailwind からは `bg-[var(--brand)]` または
`tailwind.config` の `theme.extend.colors` にマッピングして使う。
