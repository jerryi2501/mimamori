## 企業デー用（9月4日・本番用）

### 【0:00–0:20】つかみ

> こんにちは。作品番号 I 28−0002、Shareme の展示です。
>
> 夜、家族の帰りが遅いときに「今どこ？」とメッセージを送ったこと、ありませんか。
> 送るほうも気をつかうし、返すほうも面倒です。
> この小さなストレスをなくすのが、この Shareme です。

### 【0:20–0:50】何ができるか＝利用者のメリット

> 家族や友人でグループを作ると、お互いの現在地が地図に出ます。
> ポイントは、**誰か一人が動くと、家族全員の地図がその場で書き換わる**ことです。
>
> 自宅や学校を「場所」として登録しておけば、着いた・出たも自動で通知されます。
> だから「無事に着いた」の一言を、本人が送らなくても伝わります。

### 【0:50–1:30】システムの仕組み（＋実演）

> 作りは、React のフロントエンドと Spring Boot のサーバーに分かれています。
> 位置の更新はブラウザが30秒ごとにサーバーへ送り、
> それを他のメンバーへ配るところに **WebSocket（STOMP）** を使っています。
> 画面を読み込み直さなくても地図が変わるのは、ここが理由です。
>
> ——（ここで実演）こちらの端末を動かすと……ほら、こちらの画面の位置も変わりました。

### 【1:30–2:20】工夫した点／他作品との違い

> 工夫したのは、リアルタイムを「**配るだけ**」に絞ったことです。
> 書き込みは REST、配信だけを WebSocket に任せています。
> 双方向にすると同じ更新の経路が2本できて、どちらが正しいのか分からなくなるからです。
> 配信の出口も1か所に集めて、各サービスは「何が起きたか」を渡すだけにしました。
>
> もう一つ、この作品は「見張る」のではなく「**見守る**」という考え方で作っています。
> 共有はいつでも自分でオフにできますし、Webアプリなのでタブを閉じれば位置は送られません。
> その代わり、位置がどれくらい古いかを「5分前」のように必ず画面に出しています。
> ブラウザではバックグラウンドで追跡できない、という制約を隠さないためです。

### 【2:20–2:50】自分の担当

> 私はチーム5人のうち、**バックエンドと API 設計**を担当しました。
> Java 21 と Spring Boot 3 で REST API を作り、JWT の認証と PostgreSQL のスキーマを設計しています。
>
> 一番苦労したのは WebSocket の認証です。
> Spring Security のフィルタは HTTP のリクエストにしか効かないので、WebSocket の接続には届きません。
> そこで STOMP の CONNECT フレームでトークンを見る仕組みに切り替えて解決しました。

### 【2:50–3:00】締め

> 実際に触っていただけます。端末を2つ並べてあるので、
> 片方を動かすと、もう片方がその場で変わるところを見てみてください。

## 想定質問と答え（企業デー）

**Q. なぜ WebSocket？ポーリングではだめでしたか？**
> ポーリングだと更新の間隔ぶん必ず遅れますし、動きがない時間も通信し続けます。
> SOS のように「すぐ届いてほしい」機能があるので、サーバーから押し出す形にしました。

**Q. 認証は？**
> JWT です。ただし WebSocket には Spring Security のフィルタが届かないので、
> STOMP の CONNECT フレームで検証しています。
> ブラウザは WebSocket のハンドシェイクにヘッダーを付けられないためです。

**Q. 再接続したら購読はどうなりますか？**
> 全部消えます。なのでフロント側で購読の一覧を自分で持っておいて、
> つなぎ直したときに貼り直しています。

**Q. DB のスキーマ管理は？**
> Flyway です。`ddl-auto` は `validate` にしてあります。
> `update` だと列の削除や型変更ができないまま、本番のスキーマが少しずつ壊れていくからです。

**Q. 地図は？お金はかかりますか？**
> 地図タイルは CARTO、住所は国土地理院の API です。
> どちらも API キーもクレジットカードも不要で無料です。
> Google Maps は課金事故が怖かったので見送りました。

**Q. チームでの分担は？**
> 5人で、フロントエンド2人、バックエンド3人です。
> 私はサーバーサイドと API 設計を担当しました。

**Q. 今後やりたいことは？**
> Web Push です。今はアプリを閉じていると呼び出しの音が鳴らないので、そこを埋めたいです。

**Q.（答えられない質問が来たら）**
> すみません、そこはまだ調べられていません。
> ただ、〇〇までは分かっていて、次はこう調べようと思っています。
